# site-static/

Static assets served at the **root** of https://genesis.pixelzx.com (GitHub Pages).

This directory ships the marketing landing, install-script entry points, JSON schemas, and the `CNAME` file. The Mintlify-style docs site is built separately by [`scripts/build-github-pages-docs.mjs`](../scripts/build-github-pages-docs.mjs) and merged in under `/docs/` by the [`docs-pages.yml`](../.github/workflows/docs-pages.yml) workflow.

## Layout

| File             | Served at         | Notes                                      |
| ---------------- | ----------------- | ------------------------------------------ |
| `CNAME`          | (Pages config)    | Custom domain `genesis.pixelzx.com`        |
| `.nojekyll`      | (Pages config)    | Disable Jekyll processing                  |
| `index.html`     | `/`               | Marketing landing                          |
| `privacy.html`   | `/privacy`        | Privacy policy                             |
| `install.sh`     | `/install.sh`     | macOS/Linux installer (placeholder)        |
| `install.ps1`    | `/install.ps1`    | Windows PowerShell installer (placeholder) |
| `install-cli.sh` | `/install-cli.sh` | CLI-only installer (placeholder)           |

The build workflow additionally writes:

- `protocol.schema.json` (generated by `pnpm protocol:gen`)
- `config.json` (copy of `docs/.generated/config-baseline.json`)

into the deployed site root.

## Replacing placeholders

The `install*.sh` / `install.ps1` files in this directory are stubs that print a message and exit with code 1. Replace them with real installer scripts (typically forked from the upstream `sst/genesis` installer scripts) before announcing the new domain.
