What it does

Built for agents that actually do things.

Workspace isolation, routing, memory, approvals and automation — out of the box, on your terms.

You stay in control

Messages, sessions and credentials live on your machine. Nothing leaves unless you point it somewhere.

Multi-agent routing

Isolated agents per channel, workspace or sender — each with its own memory and tool policy.

Sandbox & approvals

Lock down sessions with Docker, SSH or OpenShell. Approve sensitive tool calls before they run.

Cron, hooks & skills

Schedule recurring jobs, react to events, and teach new skills with plain markdown.

Canvas & voice

Pair iOS and Android nodes for live canvas, camera, voice wake and push-to-talk.

Extensible by plugins

Add channels, model providers, tools and skills. The SDK and manifest format are documented.

Quick start

Five minutes to a working assistant.

Install

Grab the CLI from npm. Node 24 recommended.

npm install -g @pixelzx/genesis@latest

Onboard

The wizard installs the Gateway service and pairs your first channel.

genesis onboard --install-daemon

Chat

Open the dashboard, or message your agent from any paired app.

genesis dashboard
